# CodeArc social media kit

## Profile pictures

Use `codearc-universal-profile.png` for WhatsApp, Instagram, Facebook, LinkedIn, X, YouTube, TikTok, Telegram, and other profile images. It is centred for circular cropping.

Use `codearc-profile-with-name.png` when a square graphic should include the full CodeArc name.

For WhatsApp Business, use `codearc-whatsapp-business-cover.png` as the wide cover behind the circular profile photo.

## Animated content

- `codearc-square-animation.mp4` — Instagram/Facebook feed, LinkedIn, X, Telegram, and general square posts.
- `codearc-square-animation.gif` — chats, websites, email, and platforms that preserve GIF animation.
- `codearc-story-reel-short.mp4` — WhatsApp Status, Instagram/Facebook Stories and Reels, YouTube Shorts, TikTok, Snapchat, and Telegram Stories.
- `codearc-landscape-animation.mp4` — YouTube, Facebook, LinkedIn, X, presentations, and widescreen posts.
